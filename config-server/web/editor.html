管理远程配置源地址

远程配置文件

按配置项生成 remote.config.json，可直接下载使用；如需更高安全性，再执行 AES-256-GCM 加密。

操作流程
1. 填写配置项直接填写面板类型、官网地址、提供商标识和站点列表，系统会实时生成 remote.config.json。
2. 下载并使用 JSON如果不需要加密，确认无误后直接下载 remote.config.json 并上传到 OSS，即可作为远程配置文件使用。
3. 按需加密配置文件 推荐操作首次加密建议点击“生成密钥并加密配置文件”；如果是后续更新配置，直接填写已保存的密钥，再点击“使用当前密钥加密”。
4. 保存密钥并下载加密后的配置文件首次加密后请务必保存好密钥，并将该密钥填写到远程配置源的“加密密钥（可选）”中；后续如需二次加密，继续使用这把密钥即可。
remote.config.json 配置项
请选择当前站点使用的面板类型；如果是 xiaov2board，请选择 v2board。
这里填写软件内“官网入口”打开的地址，通常就是你的主站域名，例如 https://your-site.com 。
这里非常重要：填写的值必须与基础设置里的“提供商标识（provider）”完全一致，包括大小写；remote.config.json 会用它作为 panels 的键名，如果不一致，软件可能无法正确识别站点，甚至无法正常启动。
站点列表（panels）
面板类型、提供商标识、至少一个站点地址（url）为必填；站点说明（description）留空时会自动使用“站点1、站点2 ...”。
加密与密钥
请先完善必填项；如果不需要加密，可直接下载使用。首次加密建议点击“生成密钥并加密配置文件”，后续更新配置可填写原密钥后点击“使用当前密钥加密”。
首次加密请直接点击“生成密钥并加密配置文件”，系统会自动生成新密钥；如果是二次加密或更新配置，请在这里填写首次保存的密钥，再点击“使用当前密钥加密”，这样不会和旧密钥冲突。
最近保存记录
仅保留当前浏览器最近保存的 10 条 remote.config.json 记录，可直接载入、下载或删除。
